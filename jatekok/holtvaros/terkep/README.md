# Holtváros – nyers térképadat

Ide kerül Magyarország OpenStreetMap-kivonata: `hungary-261119.osm.pbf` (forrás: download.geofabrik.de, © OpenStreetMap-közreműködők, ODbL).

A fájl Git LFS-ben tárolódik (lásd a gyökér `.gitattributes`-t), mert nagyobb a GitHub 100 MB-os fájlkorlátjánál.
A játék nem ezt tölti be: a `tools/holtvaros_terkep.py` készít belőle kicsi, játékba való adatot (`jatekok/holtvaros/terkepadat.js`).
